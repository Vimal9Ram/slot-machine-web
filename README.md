# 🎰 NEON CASINO: INTERACTIVE WEB SLOT MACHINE

An interactive, browser-based slot machine game engineered with pure HTML5, CSS3, and modern Vanilla JavaScript (ES6+). Features full reel spinning mechanics, randomized payout logic, bankroll tracking, dynamic Web Audio API sound synthesis, state persistence via localStorage, and progressive rank milestones.

🎮 **[Play Live Demo Here](https://<YOUR-GITHUB-USERNAME>.github.io/slot-machine-web/)**

---

## 🌟 Key Features

- **Dynamic Reel Engine:** Smooth visual reel-spin mechanics with randomized reel payouts and win-line evaluation.
- **Synthesized Audio Engine:** Custom spinning sounds, win chimes, and coin drop sound effects generated dynamically using the native browser **Web Audio API** (zero external MP3 assets).
- **State Persistence:** Automatically saves your chip balance, total spins, and highest balance using browser **localStorage**.
- **Dark Neon Casino UI:** Designed with an authentic dark-mode casino aesthetic, glowing accents, and clean typography using Google Fonts (**Cinzel** and **Inter**).
- **CSS Keyframe Animations:** Smooth visual blur and spin transitions triggered on every play.
- **Bankroll & Betting System:** Real-time chip tracking, customizable wager inputs, and win/jackpot payout calculations.
- **Zero Dependencies:** Built entirely with lightweight vanilla technologies without external frameworks or build tools.

## 🚀 Local Setup & Installation

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/](https://github.com/)<YOUR-GITHUB-USERNAME>/slot-machine-web.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd slot-machine-web
   ```
3. **Open in browser:**
   Open `index.html` directly in your web browser, or launch it using VS Code's Live Server extension.
